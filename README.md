# Tech Gadget Store

A modern and responsive E-Commerce frontend application developed using HTML, CSS, and JavaScript. The project showcases dynamic product rendering, interactive UI components, and clean frontend design principles suitable for beginner web development and internship portfolios.

## Features
- Dynamic product display using JavaScript
- Responsive product card layout
- Interactive “Add to Cart” functionality
- Hover animations and modern UI styling
- Clean and organized frontend structure

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## Purpose
This project was created to strengthen frontend development fundamentals and demonstrate practical implementation of responsive web design and DOM manipulation concepts.
